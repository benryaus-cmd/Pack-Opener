## Assets

All image bases were read from actual TCGdex set API responses, not constructed from guessed card IDs. The first set and eight featured images are cached in the repository (110 images). Uncached images use the returned TCGdex asset base and supported resolution suffix. Missing images display a named, styled fallback. Data snapshot and cached images are replaceable behind `src/game/catalogue.ts` and the card definition/instance split.

This is a prototype using temporary Pokémon TCG images. TCGdex code/data licensing does not license Pokémon character/card art for commercial redistribution. Replace art, names and identifiers for an original-IP release.
